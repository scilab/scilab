Welcome to Scilab 2027.0.0

Scilab 2027.0.0 is a new stable release of Scilab, the open-source platform for numerical computation.

Here is a short tour of the main changes since Scilab 2026.1.0. The complete list is detailed in the CHANGES file.

Main new features

  • SciNotes, the Scilab editor, is now web-based: completion, hover help, go to definition, syntax diagnostics and LaTeX preview. It embeds a debugger (breakpoints, step by step execution, values of the variables on hover; see doc scinotes_debugger) and an AI assistant that writes Scilab code and runs it in the session (see doc scinotes_assistant).
  • The console is now web-based: LaTeX rendering of strings, files executed by drag & drop, pasted code executed at once, and warnings and errors visually distinct from the regular output.
  • The help browser is now web-based: highlighted code, LaTeX & MathML equations, improved search, and a menu on each page to jump to its sections.
  • Xcos: the former fmu-wrapper ATOMS toolbox is now the built-in fmu module, to import and simulate FMUs (FMI 1/2/3) with importFMU() and fmiSimulate().

New functions

  • agglomerative(): Agglomerative hierarchical clustering.
  • between(): Calendar difference between two datetime values.
  • caldiff(): Calendar successive differences.
  • linkage(): Agglomerative hierarchical cluster tree.
  • silhouette(): Silhouette values of a clustering.
  • sprkode(): SUNDIALS symplectic Runge-Kutta ODE solver.

Language evolutions

  • Comparison and element-wise logical operators now perform the same automatic expansion as arithmetic operators. See doc operator_expand.
  • classdef has been extended: class names can be used as argument or property types, and validator parameters are evaluated at call time. See doc classdef.

Graphics

  • Transparency is now managed, through new *_alpha properties of the graphic entities and new options of plot(), surf(), scatter() and scatter3d(). See doc polyline_properties for example.
  • New Root and Console graphic objects: get(0) returns the Root object, whose children are the figures and the Console.

Removed functions

  • dos() and the unix*() functions: use host() instead.
  • readmps(): use the quapro toolbox instead.

Many other improvements, obsolete features and bug fixes are listed in the CHANGES file.

Documentation and help

If you are new to Scilab, please use the Scilab beginners tutorial and Xcos beginners tutorial provided by the Scilab Team.

The Scilab Team also provides some documentation and tutorials.
